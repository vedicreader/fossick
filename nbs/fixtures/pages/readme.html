fastgrep

fastgrep searches code faster than grep -r. It skips files that .gitignore names, and it reads files in parallel.

Install

pip install fastgrep

Usage

from fastgrep import search
for hit in search("TODO", root="."):
    print(hit.path, hit.line)

Options

OptionDefaultMeaning
--hiddenoffSearch hidden files too
--max-size1MSkip larger files
-j NCPU countNumber of threads
  • Regex search
  • Fuzzy search
